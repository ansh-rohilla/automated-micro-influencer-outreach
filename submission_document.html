1. Executive Summary & Architecture

This project implements an end-to-end automated system for micro-influencer discovery, qualification, enrichment, AI-driven message personalization, and outreach delivery tracking. The system extracts 58 genuine Technology & AI creator profiles, strictly applies micro-influencer criteria (5,000–100,000 followers and ≥ 2.0% engagement), enriches records under anti-fabrication standards, generates tailored pitches across 6 collaboration angles, and dispatches messages with duplicate prevention. 

Discovery (58 Real Profiles) 
    ↳ Filtering & Classification (30 Passed, 28 Failed with Audit Reason)
        ↳ Profile Enrichment (Contacts, Benchmarked Demographics, Content Tone)
            ↳ AI Personalization (60-90w Email Pitch | 15-30w Instagram DM)
                ↳ Sending Layer (Safe Simulation / SMTP + Idempotency)
                    ↳ Live Outreach Tracker (Persistent CSV / JSON Audit Log)

5. Quick Setup & Execution

# Clone repository
git clone https://github.com/ansh-rohilla/automated-micro-influencer-outreach.git
cd automated-micro-influencer-outreach

# Setup virtual environment
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

# Run full pipeline end-to-end
python main.py

# Launch interactive Streamlit web dashboard
streamlit run app.py

# Run unit tests
python -m unittest discover tests
